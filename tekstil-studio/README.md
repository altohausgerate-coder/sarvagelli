# Sarvagelli portfeli

Repozitoriyanın kökündə `python -m http.server 8000` əmri ilə önizləməni başladın və `http://localhost:8000/tekstil-studio/` ünvanını açın. GitHub Pages statik faylları birbaşa yayımlayır.

- Ana səhifədə PDF arxivindən 29 layihənin 44 fotosu görünür. Veb versiyaları `media/layiheler/`, mənbə fotoları isə repozitoriyanın `assets/projects/` qovluğundadır.
- Layihə kartları `index.html` və `layiheler.html` fayllarında, məlumat və qalereyalar `layihe-*.html` səhifələrindədir. Konsept təsvirləri ayrıca işarələnib.
- Tamamlanması üçün real materiallar tələb olunan məqamlar — yüksək ayırdetməli orijinal fotolar, hər layihənin əlavə fotoları, çəkiliş və layihə tarixləri, komanda üzvlərinin portretləri və bioqrafiyaları, arxiv şəkilləri və təsdiqlənmiş tarixçə məlumatları.
- Əlaqə forması e-poçt proqramında məktub qaralaması açır. Sayt üzərindən birbaşa göndəriş üçün ayrıca xidmət lazımdır. Yerli video yayımlamaq üçün orijinal MP4 faylı əlavə edilməlidir.
